# Unirack-1 — обновление прошивки (исправление MAC-адресов)

## Что исправляет обновление

В первой версии прошивки все устройства Unirack-1 имели **одинаковый
MAC-адрес**, из-за чего два и более устройства не могли работать в одной
локальной сети. После обновления каждое устройство получает **уникальный
MAC-адрес автоматически** (он формируется из серийного номера процессора,
вид `02:08:DC:xx:xx:xx`).

Настройки устройства при обновлении **сохраняются**: IP-адрес, шлюз,
маска, параметры MQTT — всё остаётся как было.

## Что понадобится

- Ноутбук/ПК с Windows 10/11 и правами установки программ
- USB-кабель Type-A ↔ Micro-USB/Type-C **с линиями данных** (не «только зарядка»)
- Крестовая отвёртка
- Эта папка с файлами: `main.py`, `w5500_simple.py`, `update_unirack.ps1`, `ЗАПУСК.bat`

## Подготовка компьютера (один раз)

1. Установите Python с сайта https://www.python.org/downloads/
   (при установке отметьте галочку **Add python.exe to PATH**).
2. Откройте командную строку (Win+R → `cmd` → Enter) и выполните:
   ```
   pip install mpremote
   ```

## Обновление каждого устройства (~2 минуты на штуку)

1. Открутите **переднюю панель** устройства (та, на которой нет разъёмов).
   За ней находится USB-кабель.
2. Подключите этот USB-кабель к компьютеру.
   Питание устройства при этом отключать не обязательно.
3. Запустите обновление **двойным кликом по файлу `ЗАПУСК.bat`**.
   Окно не закроется само — все сообщения останутся на экране.
4. Дождитесь зелёной надписи **ГОТОВО** — скрипт сам найдёт устройство,
   зальёт прошивку, проверит её и перезагрузит устройство.
   Скрипт также покажет новый MAC-адрес устройства.
5. Отключите USB, прикрутите панель. Устройство готово.

Повторите для каждого устройства.

## Проверка

Откройте веб-интерфейс устройства (его IP в браузере). В верхней строке
рядом с `Board IP` теперь показан MAC-адрес. У разных устройств
он должен быть **разным** (совпадают только первые три пары `02:08:DC`).

## Важно при работе нескольких устройств в одной сети

- У каждого устройства должен быть **свой IP-адрес**. С завода все идут
  с `192.168.1.100` — подключайте новые устройства к сети **по одному**
  и сразу задавайте им разные IP в блоке «Board Network» веб-интерфейса.
- При работе через общий MQTT-брокер задайте каждому устройству свой
  **Base Topic** (`unirack1`, `unirack2`, …) в блоке «MQTT Settings».

## Если что-то пошло не так

- Окно командной строки мелькает и сразу закрывается — вы запустили
  `update_unirack.ps1` напрямую. Запускайте через **`ЗАПУСК.bat`** —
  он держит окно открытым и показывает, что случилось.
- «Плата не найдена» — проверьте кабель (нужен кабель с данными),
  попробуйте другой USB-порт.
- «Не найден mpremote» — повторите раздел «Подготовка компьютера».
- Ошибка на середине — отключите/подключите USB и запустите скрипт ещё раз:
  повторный запуск безопасен.
- Контакты поставщика — см. договор.
