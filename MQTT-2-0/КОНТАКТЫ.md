# Unirack-1 — названия контактов (клеммник)

| Клемма | Название | Английское имя | Контакт | После подачи питания |
|--------|----------|----------------|---------|----------------------|
| Реле 1 | Розетка 1 | PowerOutlet1 | НЗ | ВКЛ (запитано) |
| Реле 2 | Розетка 2 | PowerOutlet2 | НЗ | ВКЛ (запитано) |
| Реле 3 | Розетка 3 | PowerOutlet3 | НЗ | ВКЛ (запитано) |
| Реле 4 | Розетка 4 | PowerOutlet4 | НЗ | ВКЛ (запитано) |

| Реле 6 | Блок питания 2 | PowerSupply2 | НЗ | ВКЛ (запитано) |

## Цифровые входы (замыкание на GND/DGND)

| Клемма | Название | Английское имя | Примечание |
|--------|----------|----------------|------------|
| DI3 | Цифровой вход 1 | DigitalInput1 | |
| DI4 | Цифровой вход 2 | DigitalInput2 | |
| DI5 | Цифровой вход 3 | DigitalInput3 | |
| DI6 | Сброс настроек | Reset | Замкнуть на ~2 с → сброс IP на 192.168.1.100 |
| DI7 | Дверь 1 | Door1 | Замкнут = дверь закрыта |
| DI8 | Дверь 2 | Door2 | Замкнут = дверь закрыта |

DI1, DI2 — не выведены, не используются.

## Измеритель электропитания (EnergyMonitor)

Подключается измеритель питания (опционально, например PZEM-004T).

| Клемма | Назначение |
|--------|------------|
| EM TX | Передача данных (→ RX измерителя) |
| EM RX | Приём данных (→ TX измерителя) |
| +5 | Питание измерителя 5 В |
| GND | Земля |

## Датчик температуры (TemperatureSensor)

Параллельно подключаются датчики DS18B20 (3 шт. в комплекте).
Общий резистор 4.7 кОм между TS Data и VDD.

| Клемма | Назначение |
|--------|------------|
| TS Data | Данные 1-Wire (жёлтый/белый провод) |
| VDD | Питание 3.3 В (красный провод) |
| GND | Земля (чёрный провод) |

## Датчик температуры и влажности (TempHumSensor)

Подключается датчик DHT22 (1 шт. в комплекте).

| Клемма | Назначение |
|--------|------------|
| THS Data | Данные |
| VDD | Питание 3.3 В |
| GND | Земля |

## Прочее
