Как заливать прошивку в новые платы Unirack-1 и обновлять устройства, уже стоящие у заказчика. Все файлы — в репозитории https://github.com/Korvova/waveshare, папка `MQTT-2-0`.

## Устройство прошивки

На плате стоит MicroPython — «прошивка» это два файла, копируемых по USB:

- `main.py` — вся логика: веб-интерфейс, MQTT, реле, датчики;
- `w5500_simple.py` — драйвер Ethernet-чипа W5500.

Компиляторы, Arduino IDE и драйверы не нужны: плата определяется в Windows 10/11 как COM-порт сама (VID 2E8A — Raspberry Pi). Загрузчик не трогается, «кирпич» сделать невозможно: неудачная заливка просто оставляет старую прошивку.

## Прошивка новой платы (у нас)

Нужны: Python + `pip install mpremote`, USB-кабель **с линиями данных**.

```powershell
cd C:\Users\Владимир\Documents\App\waveshare\MQTT-2-0
powershell -ExecutionPolicy Bypass -File flash_unirack.ps1
```

Скрипт сам: находит плату по VID, копирует оба файла (с повторами — плата может ещё грузиться), сверяет размеры на плате с эталоном, удаляет `mqtt_config.json` (заводские настройки для новой партии) и перезагружает. ~20 секунд на устройство, дальше просто втыкать следующую и запускать снова.

Проверка после прошивки: открыть `http://192.168.1.100` — страница «Unirack-1», реле 1–7 в ON, реле 8 в OFF, MAC рядом с Board IP.

## Обновление устройств у заказчика

USB-кабель — **за передней панелью без разъёмов** (открутить отвёрткой). OTA нет, обновление только по USB.

Готовый пакет для самостоятельного обновления айтишником заказчика: `MQTT-2-0/Unirack-1-update-MAC.zip` (собран из `MQTT-2-0/update-package/`). Внутри:

- прошивка (`main.py`, `w5500_simple.py`);
- `update_unirack.ps1` — то же, что flash-скрипт, но **сохраняет настройки устройства** (IP и MQTT не сбрасываются), проверяет наличие mpremote с человеческой подсказкой и в конце печатает новый MAC;
- `ОБНОВЛЕНИЕ.md` + PDF — инструкция «с нуля»: установка Python, pip install mpremote, порядок действий, раздел «если что-то пошло не так».

## Грабли (проверено на партии из 12 штук)

1. **Кабель «только зарядка»** — самая частая причина «плата не найдена»: питание есть, данных нет. Менять кабель.
2. **mpremote: could not enter raw repl** — плата ещё грузится в момент подключения. Лечится повтором; в обоих скриптах повторы встроены (до 4 раз).
3. **`.ps1` с кириллицей — только UTF-8 с BOM.** Без BOM PowerShell 5.1 читает файл как cp1251 и ломается на парсинге (второй байт буквы «Г» совпадает с типографской кавычкой).
4. **`machine.reset()` рвёт serial-связь** — mpremote завершится с ошибкой, это норма: reset уже прошёл. Порт исчезает на ~2–4 с и появляется снова.
5. **COM-порт у каждой платы свой** (и растёт с каждой новой) — поэтому скрипты ищут плату по VID 2E8A, а не по номеру порта.
6. **Несколько устройств в одной сети**: у всех с завода IP `192.168.1.100` — подключать по одному и сразу задавать разные IP; при общем MQTT-брокере — разные Base Topic. До фикса `9aca0d6` был ещё и одинаковый MAC — см. [Т. Прошивка](/homepage/iniciativa.-proekty-rms/jepik-waveshare-unirack/t-proshivka), п. 5.

## Проверка вебки без платы

`python MQTT-2-0/local_preview.py [порт]` — поднимает настоящий веб-интерфейс прошивки на ПК (железные модули подменяются заглушками, датчики показывают демо-значения). Удобно для скриншотов и проверки правок интерфейса до заливки.

## Версии

Актуальная прошивка — всегда `MQTT-2-0/main.py` в `main`-ветке репозитория; скрипты сверяют размер файла на плате с этим эталоном. История: партия 10.07.2026 отгружена с одинаковым MAC; фикс уникальных MAC/Client ID — коммит `9aca0d6` (18.09.2026).
